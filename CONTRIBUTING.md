## Accepting the agreement

Before we can merge your first pull request, you need to accept the Artlite Contributor Assignment Agreement below.
Under it you assign the copyright in your contributions to the Artlite Project, the owner of the `artlite-project`
organization on GitHub, and grant a patent license for them. Read it before accepting it.

To accept it, post this comment on your pull request from your GitHub account:

```
I have read the Artlite Contributor Assignment Agreement, version 1.0, and I accept it for all my Contributions to Artlite.
```

You accept it once: it then covers all your contributions. If your employer has rights to what you create, make sure
it permits you to contribute under the agreement (section 4.2) before you accept.

Code from another project keeps its copyright and license notices: say in the pull request where it comes from and
under which license (section 4.4).
